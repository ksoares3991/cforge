# cforge

Bash automation tool for C projects.

## Prerequisites

- Linux (or Git Bash / WSL on Windows)
- Bash 4+
- gcc installed

## Expected project structure

```
project/
├── src/      # .c source files
├── include/  # .h header files
├── build/    # generated by the tool
└── logs/     # generated by the tool
```

## Syntax

```
bash cbuild.sh <command> [options] [directory]
```

## Commands

| Command | Description                        |
|---------|------------------------------------|
| build   | Compiles the project               |
| run     | Runs the compiled program          |
| clean   | Removes build artifacts            |
| rebuild | Cleans and recompiles              |
| info    | Displays project statistics        |

## Options

| Option            | Description                                    |
|-------------------|------------------------------------------------|
| --opt=0\|1\|2     | Optimization level (-O0/-O1/-O2)               |
| --no-incremental  | Forces recompilation of all files              |
| --verbose         | Shows steps and commands executed              |
| --debug           | Shows internal variables (stderr)              |
| --report          | Generates reports/report.html (info command)   |

## Examples

```bash
bash cbuild.sh build /my/project
bash cbuild.sh build /my/project --opt=2
bash cbuild.sh build /my/project --verbose
bash cbuild.sh run /my/project
bash cbuild.sh clean /my/project
bash cbuild.sh rebuild /my/project --opt=1
bash cbuild.sh info /my/project
bash cbuild.sh info /my/project --report
```

## Incremental build

`.c` files not modified since the last build are not recompiled. Use `--no-incremental` to force a full recompilation.

## Configuration file

Create `cbuild.conf` at the project root:

```
EXEC_NAME="my_program"
```

## Logs

Each execution appends a record to `logs/cbuild.log` with date, time, command, execution time, and return code.
